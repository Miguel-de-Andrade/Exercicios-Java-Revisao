Lista de Revisão – Programação de Algoritmos

Este repositório reúne as resoluções dos exercícios da **Lista de Revisão** da disciplina **Programação de Algoritmos**, ministrada pelo **Prof. Carlos Alberto**.

Objetivo

O objetivo desta lista é revisar e consolidar os principais conceitos da linguagem **Java**, desenvolvendo a lógica de programação e a capacidade de resolução de problemas por meio de exercícios práticos.

Conteúdo

Os exercícios abordam temas como:

- Variáveis e tipos de dados;
- Entrada e saída de dados com `JOptionPane`;
- Operadores aritméticos, relacionais e lógicos;
- Estruturas condicionais (`if`, `else if` e `else`);
- Cálculos matemáticos;
- Desenvolvimento da lógica de programação.
